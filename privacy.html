EVA

Privacy policy

Last updated: 5 November 2026

EVA is a private, single-user personal assistant made by Riyan Khan for his own use. The only person whose data EVA handles is Riyan himself. EVA has no other users and is not offered to the public.

Google data EVA can access

Only after Riyan signs in with his own Google account and grants permission, EVA can:

  • Gmail — read and search his messages to summarise them for him; create draft emails; send an email only after Riyan reviews and approves that specific email in the EVA app.
  • Google Calendar — read his events, add events he asks for, and change or delete an event only after he approves it.
  • Google Tasks — read, add and complete his to-dos.
  • Google Drive — create files (for example notes) and access only the files EVA itself created. EVA cannot see his other Drive files.

How the data is used

  • Only to provide EVA's features to Riyan: answering his questions, summaries, drafts, reminders, the morning brief and night recap.
  • Never for advertising, never sold, never used to build profiles for anyone else, and never used to train AI models.
  • To understand a request and write a reply, the relevant text (for example the subject and content of an email Riyan asked about) is sent to Anthropic's Claude API, which processes it to generate the answer. Anthropic does not use API data to train its models by default. No other third party receives Google data.
  • No human reads the data, except Riyan himself.

Storage and security

  • EVA runs on Riyan's own private server (Oracle Cloud, India), reachable only through his private network. It is not exposed to the public internet.
  • The Google sign-in token is stored only on that server as a protected secret file. Chat history, memories and summaries are stored encrypted in its database.
  • Email content is fetched when needed and is not copied in bulk or kept as a separate archive.

Removing access and data

  • Riyan can revoke EVA's access at any time at myaccount.google.com → Third-party connections, or with EVA's own disconnect command, which revokes the token and deletes it from the server.
  • Conversations, memories and other stored data can be deleted from inside the EVA app.

Google API Services User Data Policy

EVA's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
